  <name>Task 1: Create WiFi watchdog script with multi-stage validation and recovery</name>
  <files>watchdog/wifi-watchdog.sh</files>
  <action>
Create `watchdog/wifi-watchdog.sh` following the exact patterns from touchscreen-check.sh and the research code examples.

Script structure:
1. Shebang `#!/bin/bash` with `set -euo pipefail`
2. SCRIPT_DIR/REPO_ROOT derivation pattern (identical to touchscreen-check.sh)
3. `source "$REPO_ROOT/lib/config.sh"`
4. Load config values:
   - `WIFI_SSID="$(cfg_require '.wifi.ssid')"`
   - `WIFI_PASSWORD="$(cfg_require '.wifi.password')"`
   - `DASHBOARD_URL="$(cfg_require '.dashboard.url')"`
   - `FLAG_FILE` from cfg_get with default `/var/run/wifi-reboot-attempted` (separate from touchscreen flag)
   - `LOG_TAG` from cfg_get with default `wifi-watchdog`
5. `log_message()` function using `logger -t "$LOG_TAG"` plus echo (same pattern as touchscreen-check.sh)
6. `check_network()` function with 4 stages:
   - Stage 1: Ping default gateway (`ip route | grep default | awk '{print $3}' | head -1`, `ping -c 1 -W 5`)
   - Stage 2: Ping public DNS 8.8.8.8 (`ping -c 1 -W 5 8.8.8.8`)
   - Stage 3: DNS resolution (`host google.com`)
   - Stage 4: HTTP check dashboard URL (`curl --max-time 10 --silent --output /dev/null "$DASHBOARD_URL"`)
   - Return 0 if ANY stage passes (network is working). Return 1 only if ALL fail.
7. `apply_wifi_credentials()` function using nmcli:
   - Check if connection profile exists: `nmcli -t -f NAME connection show | grep -q "^${WIFI_SSID}$"`
   - If exists: `sudo nmcli connection modify "$WIFI_SSID" wifi-sec.key-mgmt wpa-psk wifi-sec.psk "$WIFI_PASSWORD"`
   - If not: `sudo nmcli connection add type wifi con-name "$WIFI_SSID" ifname wlan0 ssid "$WIFI_SSID"` then modify
   - Bring up: `sudo nmcli connection up "$WIFI_SSID"`
8. `recover_network()` function with staged recovery:
   - Stage 1: nmcli down/up cycle for existing connection
   - Stage 2: Apply credentials from config and reconnect
   - Stage 3: Restart NetworkManager (`sudo systemctl restart NetworkManager`)
   - After each stage, sleep 15 seconds and re-check network. If check_network passes, log success and return 0.
   - If all stages fail, check flag file before rebooting:
     - If FLAG_FILE exists: log "Reboot already attempted, manual intervention required", exit 1
     - If not: touch FLAG_FILE, log "REBOOTING", `systemctl reboot`
9. Main logic:
   - If check_network succeeds: clear flag file if it exists (same as touchscreen-check.sh), log "Network OK", exit 0
   - If check_network fails: log "Network check failed", call recover_network
10. Signal browser reload after successful recovery by touching a signal file `/tmp/wifi-recovered` (Plan 02's browser watchdog will check this).

Mark script executable with `chmod +x` in the task verification.

IMPORTANT: The flag file path MUST be different from the touchscreen flag file (`/var/run/touchscreen-reboot-attempted`). Use `/var/run/wifi-reboot-attempted` as default. Both use /var/run/ (tmpfs, cleared on power cycle).

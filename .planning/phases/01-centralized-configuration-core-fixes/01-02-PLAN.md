**kiosk/kiosk.sh:**

Rewrite to load all values from config.json via `lib/config.sh`:

1. Determine REPO_ROOT from script location: `SCRIPT_DIR="$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)"` then `REPO_ROOT="$(cd "$SCRIPT_DIR/.." && pwd)"`
2. Source the config loader: `source "$REPO_ROOT/lib/config.sh"`
3. Replace hardcoded values:
   - `http://192.168.68.75:8123` → `cfg_require '.dashboard.url'`
   - `sleep 10` → `sleep "$(cfg_get '.kiosk.desktop_load_wait_seconds')"` (default 10)
   - `--user-data-dir="$HOME/.config/chromium-kiosk"` → `--user-data-dir="$(cfg_require '.kiosk.user_data_dir')"`
   - `800x300` onboard size → `cfg_get '.kiosk.onboard_size'`

4. **REMOVE `--disable-web-security` flag entirely** (CLN-03). This flag was never needed — the dashboard is on the same local network and HA handles auth via trusted networks. No replacement flag needed.

5. Keep these Chromium flags as they serve valid purposes:
   - `--kiosk` (fullscreen mode)
   - `--disable-infobars` (no info bars)
   - `--disable-session-crashed-bubble` (no crash bubbles — BRW-05 related)
   - `--disable-restore-session-state` (no restore dialog — BRW-05 related)
   - `--disable-features=TranslateUI` (no translation prompts)
   - `--no-first-run` (skip first-run experience)
   - `--fast` and `--fast-start` (performance)
   - `--disable-default-apps` (no default apps)
   - `--password-store=basic` (prevents keyring popups)
   - `--display=:0` (explicit X display)

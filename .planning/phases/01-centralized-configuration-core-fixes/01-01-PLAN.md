Key design choices (Claude's discretion):
- `port` is a number (not string), so the placeholder has no quotes
- Topics included in config so they're not hardcoded in mqtt_listener.py
- `heartbeat_interval_seconds` for MQTT-04 (will be consumed in Plan 03)
- `wayland_display` for display_control.py's wlopm env
- All timing values (sleep durations) are configurable
- `__CHROMIUM_USER_DATA_DIR__` defaults to `$HOME/.config/chromium-kiosk` but user can override
- `wifi` section for CFG-05 (consumed by Phase 2 watchdog, but field defined now)
- `home_assistant.auth_method` for CFG-06 (documents how HA auth works, consumed in Phase 2)
- `browser.inactivity_timeout_seconds` for CFG-07 (default 600s = 10 min, consumed in Phase 2)
- `browser.scheduled_reboot_interval_hours` for CFG-08 (default 48h = 2 days, consumed in Phase 2)

Create `lib/config.sh` — a bash library that other scripts source to load config:
- Define `CONFIG_FILE` as `$REPO_ROOT/config.json` (where `REPO_ROOT` is derived from the script's own path by walking up)
- Provide a `cfg_get` function that uses `jq` to extract a value by JSON path (e.g., `cfg_get '.dashboard.url'`)
- Provide a `cfg_require` function that calls `cfg_get` and exits with an error if the value is empty/null
- Include `jq` availability check at source time with helpful error message
- Add `jq` to bootstrap's apt package list (done in Plan 04)

Create `lib/config.py` — a Python module that other scripts import to load config:
- Define `CONFIG_FILE` as `Path(__file__).resolve().parent.parent / "config.json"`
- Provide a `load_config()` function returning the parsed dict
- Provide a `get(path: str, default=None)` function that navigates nested keys with dot-notation (e.g., `get("mqtt.broker")`)
- Provide a `require(path: str)` function that raises `ConfigError` if missing
- Cache the loaded config so multiple `get()` calls don't re-read

Update `.gitignore`:
- Add `config.json` to the gitignore (at repo root level)
- Keep the old `config/mqtt.json` entry for safety during transition
- Remove any stale entries that no longer apply after restructure

Do NOT create `config.json` itself — that's bootstrap's job (Plan 04).

**Heartbeat (MQTT-04):**

Add a periodic heartbeat mechanism so Home Assistant can detect zombie MQTT connections (where TCP is alive but the listener is stuck/frozen).

Implementation approach:
1. In the main `while self.should_run` loop, add a heartbeat timer
2. Every `heartbeat_interval` seconds (from config, default 60), publish availability "online" to the availability topic
3. This is a simple re-publish of the availability message — if it stops arriving, HA knows the connection is zombie

```python
# In run() method, replace the simple sleep loop:
last_heartbeat = time.time()
while self.should_run:
    now = time.time()
    if now - last_heartbeat >= self.heartbeat_interval:
        self._publish_heartbeat()
        last_heartbeat = now
    time.sleep(1)
```

Add `_publish_heartbeat()` method:
```python
def _publish_heartbeat(self):
    """Publish periodic heartbeat to availability topic."""
    if self.client and self.client.is_connected():
        self.client.publish(TOPIC_AVAILABILITY, "online", qos=1, retain=True)
        logger.debug("Heartbeat published")
```
